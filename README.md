## Описание

Это учебный проект — разработка анимаций для страницы «Связь» сайта Whitemark на основе дизайна из Figma и видеоматериала.

## Функционал

- Бесконечная CSS-анимация движения основной фотографии на странице (плавное масштабирование и смещение)
- Анимация открытия/закрытия бургер-меню с плавным появлением вложенных элементов
- Анимации выполнены через transition с использованием CSS-переменных (тайминг и easing-функции)
- Для смещений использовано свойство transform (анимируемый элемент не сдвигает соседние блоки и не создаёт горизонтальный скролл)
- Настроена компиляция SCSS → CSS через Live Sass Compiler

## Технологии

- HTML5
- CSS3 / SCSS
- CSS-анимации (transition, transform, @keyframes)
- Figma
- Live Sass Compiler

## Инструкция по запуску

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/ChelseaSmileXx/animations.git
   ```

2. Перейдите в папку проекта:
   ```bash
   cd animations
   ```

3. Откройте файл index.html в браузере (или используйте Live Server в VS Code)
